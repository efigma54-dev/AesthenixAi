## 🎬 Critical Assets

1. **Demo GIF** (30-45 seconds) — MOST IMPORTANT
   - Shows: Open file → Run analysis → See results → Apply fix
   - Tool: ScreenToGif (Windows) or Kap (Mac)
   - Target: < 5 MB

2. **Screenshots** (minimum 2)
   - VS Code analysis view
   - GitHub PR review

3. **VS Code Marketplace Listing**
   - Demo GIF in first slot
   - Keyword-rich description
   - 5 screenshots

4. **GitHub README**
   - Demo GIF at top
   - Clear positioning
   - Quick start guide
