## 💡 Pro Tips

### Demo GIF

- Show, don't tell (real code, real results)
- Keep it short (30-45 seconds max)
- Focus on "wow moment" (instant results)
- Use obvious issues (nested loops, long methods)

### VS Code Marketplace

- Optimize for search (keywords developers search for)
- Demo GIF first (most important asset)
- Clear value prop ("Catch risky code before review")
- Social proof (GitHub stars once you have them)
