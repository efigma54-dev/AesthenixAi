- Finds bugs, security issues, and code smells
- Suggests fixes with one click
- Integrates with VS Code and GitHub PRs

**Tech stack:**

- Backend: Spring Boot + JavaParser + Ollama
- Frontend: React + Vite + Monaco Editor
- Extension: VS Code TypeScript
- Deployment: Render + Vercel
