## ⏰ Hour-by-Hour Breakdown

### Hour 1: Create Demo Assets (60 min)

**Why:** A great demo GIF converts 10x better than text

**Tasks:**

1. **Install screen recorder** (5 min)
   - Windows: [ScreenToGif](https://www.screentogif.com/)
   - Mac: [Kap](https://getkap.co/)
   - Cross-platform: [OBS Studio](https://obsproject.com/)

2. **Record demo GIF** (30 min)
   - Open VS Code with a Java file
   - Right-click → "Review with AI"
   - Show analysis appearing (5 sec)
   - Highlight 2-3 issues found (10 sec)
   - Show fix suggestion (5 sec)
   - Show GitHub PR comment (5 sec)
   - **Total:** 30 seconds of pure value

3. **Optimize GIF** (10 min)
   - Keep under 5MB for GitHub
   - 10-15 fps is enough
   - Crop to relevant area only
   - Use [ezgif.com](https://ezgif.com/optimize) if needed

4. **Take screenshots** (15 min)
   - VS Code extension in action
   - GitHub PR with annotations
   - Web dashboard view
   - Results panel with issues
   - **Save as:** `demo.gif`, `screenshot-1.png`, etc.

**Output:** `demo.gif` + 4 screenshots ready for marketplace

---

### Hour 2: Publish VS Code Extension (60 min)

**Why:** Easiest acquisition channel with built-in distribution

**Tasks:**

1. **Create publisher account** (15 min)
   - Go to [marketplace.visualstudio.com](https://marketplace.visualstudio.com/manage)
   - Sign in with Microsoft account
   - Create publisher ID (e.g., "aesthenixai")

2. **Prepare extension package** (15 min)

   ```bash
   cd vscode-extension
   npm install -g vsce
   vsce package
   # Creates: aesthenixai-x.x.x.vsix
   ```

3. **Create marketplace listing** (20 min)
   - Upload `.vsix` file
   - Add demo GIF (first slot!)
   - Add screenshots
   - Write description:

     ```
     Ship cleaner pull requests with AI-powered code review.

     ✨ Features:
     • Instant analysis in VS Code
     • Inline issue highlights
     • One-click fixes
     • GitHub PR integration

     🚀 Get feedback in under 60 seconds
     ```

   - Add tags: java, code-review, ai, quality, static-analysis
   - Set category: Programming Languages

4. **Publish** (10 min)
   - Click "Publish"
   - Wait for validation (5-10 min)
   - Verify listing is live

**Output:** Extension live on VS Code Marketplace
